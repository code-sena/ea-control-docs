¿Qué es EduAirControl?

Plataforma de monitoreo ambiental para instituciones educativas: sensores IoT en cada ambiente, un backend de microservicios y aplicaciones web y móvil.

  1. El sensor envía lecturas por Wi-Fi.
  2. El sistema evalúa umbrales y genera alertas.
  3. El usuario consulta dashboards y recomendaciones.
